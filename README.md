# Design and Analysis of Algorithms (DAA)

This repository contains C programs and solutions for various Design and Analysis of Algorithms (DAA) lab exercises, covering algorithm analysis, greedy methods, dynamic programming, divide and conquer, and competitive programming.

## 📚 Topics Covered

### 1. Finding the Complexity of an Algorithm

* Time complexity analysis using the counter method
* Loop execution and operation counting
* Analyzing nested loops
* Reversing a number using loops

**File:** `Finding the complexity of algorithm_01.pdf`

### 2. Greedy Method

* Minimum currency change
* Assigning cookies to children
* Minimizing calorie expenditure
* Maximizing weighted array sums
* Minimizing the sum of products of two arrays

**File:** `GREEDY METHOD_02.pdf`

### 3. Dynamic Programming

* Counting ways to represent a number using 1 and 3
* Finding the maximum-value path in a chessboard
* Longest Common Subsequence (LCS)
* Longest Non-decreasing Subsequence

**File:** `dynamic_programming_03.pdf`

### 4. Divide and Conquer

* Counting zeros in a sorted binary array
* Finding the majority element
* Finding the floor of a number in a sorted array
* Finding a pair with a given sum
* Quick Sort

**File:** `DIVIDE AND CONQUER_04.pdf`

### 5. Competitive Programming

* Finding duplicates in an array
* Finding the intersection of two sorted arrays
* Finding a pair with a given difference
* Comparing solutions with different time complexities

**File:** `Competitive_programing_05.pdf`

## 🛠️ Language and Tools

* **Programming Language:** C
* **Core Concepts:** Algorithm design, problem-solving, and time complexity analysis
* **Compiler:** GCC or any compatible C compiler

## 🎯 Objective

To practice fundamental algorithmic techniques, understand their implementation in C, and explore different approaches to solving computational problems.
